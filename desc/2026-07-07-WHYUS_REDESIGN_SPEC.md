# 🎨 TimeCollate 核心价值区（Why Us）组件重构设计规格书

## 1. 重构背景与设计目标
目前 TimeCollate 首页的 `WhyUs` 板块（核心价值区）采用传统的 SaaS 产品三栏式“图标 + 标题 + 简短描述”布局。该布局存在以下痛点：
* **视觉扁平平淡**：缺乏呼吸感和高定质感，无法契合 TimeCollate “技术与人文交织”的品牌调性。
* **信息承载不足**：空间固定且文案过短，无法深度体现“自由画布”、“仿生 3D 物理翻页”以及“高定实体精装印刷”三大核心壁垒的独特优势。

本方案旨在推翻现有三栏卡片设计，重构为**左侧多媒体拟物大秀场 + 右侧悬停展开文本控制区**的 PC 端奢华互动方案，并针对**移动端进行硬解码原生 `<video>` / 轻量拟物卡片无缝降级**。

---

## 2. 核心架构设计

### 2.1 整体分流架构
* **PC 端 (宽屏)**：
  * **布局**：左右分栏（左侧 6/12 宽度为 `ValueShowcasePanel` 动态视觉秀场区，右侧 6/12 宽度为悬停控制区）。
  * **交互**：鼠标悬停（`onMouseEnter`）右侧任一核心价值项时，对应项平滑展开详细描述（`max-h` 展开动画），左侧秀场区自动同步加载/切换对应的多媒体内容。
* **移动端 (窄屏)**：
  * **布局**：垂直单列堆叠布局。
  * **交互**：平铺展示三大核心价值，去除悬停逻辑，每一项下方直接嵌入多媒体展示盒，使用原生 `<video>` 自动循环静音播放；若视频不可用，降级为轻量级 CSS 拟物微场景。

### 2.2 多媒体加载与兜底机制
秀场区优先尝试渲染对应的功能演示短片。由于当前项目 `public/videos/` 路径下未提供 `features-*.mp4` 资源，特设计一套 **CSS 3D/2D 物理拟物动态组件** 作为兜底：
```
[ activeTab 改变 ]
       │
       ▼
 尝试加载 <video>
       │
 ┌─────┴─────┐
加载成功    加载失败 (无资源)
 │           │
 ▼           ▼
播放视频   渲染 `ValueShowcasePanel` 对应的纯 CSS 拟物微场景
```

## 3. 拟物微场景动效规格 (CSS Fallback)

### 3.1 自由画布 · 舞台模式 (Canvas Stage)
* **背景底饰**：采用暖调奶油色格线底纸（格线间距 `24px`，线色 `#E1DDD5`），顶部为拟物状态栏（红黄绿三色控制点、虚拟文件名 `TimeCollate_Canvas_V2.0.snb`、`100% 自动锁定比例` 徽章）。
* **核心元素**：
  * **Polaroid 拍立得照片**：渲染一张带大投影（`shadow-2xl`）的旅行照片（如西藏骑行），下方带有手写体字样（`🚴‍♂️ 西藏骑行记 · 318国道`）。
  * **Moveable 蓝框线**：照片外围包覆高精度的蓝色控制框，4 个顶角带白色填充的蓝色锚点，顶部延伸一根旋转控制线和悬空的旋转操作柄。
  * **艺术贴纸与胶带**：右上方斜贴一条半透明莫兰迪淡黄复古胶带（`rotate[-6deg]`），左下方飘落一个金色“★ 青春纪念”徽章贴纸。
* **动画逻辑**：照片及控制线框在进入时触发 `photo-drag-in` 关键帧动画：从右侧 3D 空间滑入并微幅旋转下落至画布中央，随后胶带与贴纸进行微幅的呼吸浮动。

### 3.2 仿生 3D · 物理翻页 (3D Page-Flip Stage)
* **背景底饰**：设定 3D 视距深度 `perspective: 1200px`，底层带有一层柔和的书本漫反射投影。
* **核心元素**：
  * **3D 书本实体模型**：由书脊（Spine）和左右两页纸张（Pages）组成。
  * **书脊部分**：使用垂直多重渐变阴影（`linear-gradient(to right, rgba(0,0,0,0.15), transparent 15%, transparent 85%, rgba(0,0,0,0.15))`）渲染凹陷感。
  * **右侧翻页**：设置 `transform-style: preserve-3d`，将旋转轴心定于书脊边缘（`transform-origin: left center`）。
* **动画逻辑**：右侧纸页在 `rotateY(0deg)` 至 `rotateY(-145deg)` 之间进行往复循环的翻书动画（配合 `ease-in-out` 的平滑贝塞尔曲线），模拟风吹动纸页的效果；同时纸页下方的阴影根据翻页角度拉长或缩短，完美还原纸张的重力感。

### 3.3 高定实体 · 精装印刷 (Premium Delivery Stage)
* **背景底饰**：雅致的莫兰迪暗色背景，带有细致的金色包边。
* **核心元素**：
  * **高定精装礼盒**：深色拟物礼盒盒身，质地微哑。
  * **精装纪念册**：一本厚重的硬壳精装画册从礼盒内缓缓滑出，书封带烫金“拾光集”Logo。
* **扫光动效**：在精装书表面覆盖一个倾斜 45 度的扫光渐变层（`linear-gradient(135deg, transparent 30%, rgba(197,160,89,0.3) 50%, transparent 70%)`），随扫光时间往复平移。
* **动画逻辑**：当处于活动状态时，书本执行 `translate-x` 和 `translate-y` 滑出礼盒，金色扫光随之亮起，呈现高奢的开箱质感。

## 4. 视觉规范与配色映射
为了与 TimeCollate 已有的视觉系统高度一致，严禁使用 Tailwind 默认的 `stone` 和 `amber`：
* **背景色**：替换 `bg-stone-50` 为 `bg-[#FDFBF7]`，替换 `bg-stone-100` 为 `bg-[#FAF7EE]`。
* **品牌金（高光/图标）**：替换 `text-amber-600` / `bg-amber-50` 为 `text-[#C5A059]` / `bg-[#FAF4ED]`。
* **正文字体**：替换 `text-stone-800` 为 `text-[#2C3539]`（莫兰迪黑金深灰），替换 `text-stone-600` 为 `text-[#56534C]`（暖木灰）。

---

## 5. 验证与回归计划
* **响应式适配测试**：在开发者工具中模拟 iPhone/iPad/PC 各种分辨率，确保移动端无缝降级，PC端交互无布局错位。
* **视频缺失容错测试**：核实当 `mediaUrl` 加载失败（触发 `onError`）或不提供时，系统能立即且流畅地展示对应的 CSS 拟物动画舞台，绝不出现空白及报错。
